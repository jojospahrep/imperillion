# Imperillion

Imperial College London trivia where the rarest answer wins.

**Play:** https://jojospahrep.github.io/imperillion/

- **Daily climb**: seven prompts a day, the same for everyone. 25 seconds and one answer per prompt. Your answer lifts off Queen's Lawn on a weather balloon, and rarer answers climb higher and score more. The full answer lists are never revealed.
- **Unlimited**: keep climbing through random prompts.
- **Party (Hot Flask)**: 2–8 players pass one device. Name an unused answer to pass the flask on before it boils over.

21 prompts, ~470 accepted answers. Abundance percentages are hand-estimated, not live player data.

Unofficial fan project, not affiliated with Imperial College London.

The whole game is a single static `index.html` with no build step.
